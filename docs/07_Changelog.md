# История изменений «ПАПИР-МАРКЕТ»

## 2026-08-07 (Мобильное меню v4.0)
### Добавлено
- Гамбургер-кнопка с анимацией в крестик (три полоски → X).
- Выпадающее мобильное меню под шапкой.
- Автоматическое закрытие меню при клике на пункт.
- Закрытие меню при клике вне его области.
- Пункт «Связаться» в мобильном меню.
- Кнопка «Получить расчёт» в мобильном меню (красная).
- MAX во все списки контактов.

### Изменено
- `css/header.css` — полностью переписан под v4.0 (гамбургер, выпадающий блок).
- `js/menu.js` — логика гамбургера, анимация, закрытие.
- Все 12 HTML-страниц — новый header с гамбургером и мобильным меню.
- `css/floating.css` — плавающие кнопки скрыты.

### Удалено
- Старое мобильное меню (выезжающая панель, оверлей).
- Плавающие кнопки WhatsApp и Telegram из всех страниц.

## 2026-08-06 (Header 2.0)
### Добавлено
- Header 2.0: компактное меню (5 пунктов), выпадающие подменю «О компании» и «Контакты».
- Кнопка «Связаться» с выпадающим списком.
- Новые размеры уголков: 60×60×3–5 мм.
- Обновлены изображения уголков (400×400 px).

### Изменено
- `css/header.css` — переписан под Header 2.0.
- `js/menu.js` — логика выпадашек и мобильного меню.
- `css/cards.css` — aspect-ratio 1:1, object-fit contain.
- `data.js` — добавлены 3 новых уголка 60×60.
- Все 12 HTML-страниц — новая шапка.

### Удалено
- «Как нас найти» и «Документы» из главного меню → перенесены в подменю.
- Отдельный телефон из шапки → заменён на кнопку «Связаться».
